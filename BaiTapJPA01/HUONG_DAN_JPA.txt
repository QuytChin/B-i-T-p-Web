BAI TAP 01 - PHIEN BAN DUNG JPA / HIBERNATE
============================================

Project này được chuyển từ JDBC thuần sang JPA theo cấu trúc của BaiTapJPA01.

Các phần đã đổi:
1. pom.xml: thêm Hibernate 6.6.1.Final + Jakarta Persistence 3.1.
2. src/main/resources/META-INF/persistence.xml: cấu hình SQL Server/JPA.
3. config/JpaConfig.java: tạo EntityManager.
4. entity/Category.java: Entity ánh xạ bảng Category(cate_id, cate_name, icons).
5. entity/User.java: Entity ánh xạ bảng [User].
6. dao/impl/CategoryDaoImpl.java: bỏ JDBC, dùng persist/merge/find/remove/JPQL.
7. dao/impl/UserDaoImpl.java: bỏ JDBC, dùng EntityManager/JPQL.
8. Controller, Service và JSP cũ được giữ chức năng; import model đổi sang entity.
9. Đã bỏ package connection vì DAO không còn dùng DBConnection/PreparedStatement/ResultSet.
10. config/TestJpa.java: test đọc danh sách Category bằng JPA.

src/main/resources/META-INF/persistence.xml

Sau khi import Maven project vào Eclipse:
- Maven > Update Project
- Chọn Tomcat 10.1
- Chạy config.TestJpa trước để kiểm tra JPA
- Sau đó Run on Server
